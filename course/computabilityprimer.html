    Section Math 303/304 handout: A computability-theory/Turing-machine primer

    Subsection Sets

    Definition 11.

    (Ignore the numbering of the items in this document. The markup language I’m using, "PreTeXt," imposes rules about how things are supposed to be numbered.)
    🔗
    A subset \(A\) of \(\mathbb{N}\) is said to be computable if there is an algorithm that will give a correct “Yes or No” answer to every question of the form “Is \(n\) in \(A\text{?}\)”
    🔗
    🔗
    Examples:
    • the set of all even natural numbers,
      🔗
    • the set of all prime numbers, and
      🔗
    • any finite set.
      🔗
    🔗

    Definition 12.

    A subset \(A\) of \(\mathbb{N}\) is said to be computably enumerable if there is an algorithm that can list its elements---or, alternatively, if there is an algorithm that can give all correct “Yes” answers to questions of the form “Is \(n\) in \(A\text{?}\)” but no “No” answers.
    🔗
    🔗

    Proposition 13.

    A set \(A\) is computable if and only if both \(A\) and its complement \(A^c\) are computably enumerable.
    🔗
    (Click on “Proof” below to see a proof of this Proposition.)
    🔗
    🔗

    Proof.

    (“\(\Longrightarrow\text{.}\)”)
    🔗
    (Sketch.) Suppose that \(A\) is computable. Run its algorithm for \(0, 1, 2, \ldots\,\text{.}\) Anytime you obtain a “Yes” answer for some \(n\text{,}\) put \(n\) on the list for \(A\text{;}\) any time you obtain a “No” answer for some \(n\text{,}\) put \(n\) on the list for \(A^c\text{.}\)
    🔗
    (“\(\Longleftarrow\text{.}\)”)
    🔗
    (Sketch.) Suppose that \(A\) and \(A^c\) are both computably enumerable. The algorithm for answering a question of the form “Is \(n\) in \(A\text{?}\)” is essentially “Watch both lists”: The number \(n\) has to appear eventually on either the \(A\) list or the \(A^c\) list, and when it appears on one of them, then you will know whether it is an element of \(A\text{.}\)
    🔗
    🔗
    🔗

    Subsection Functions

    Definition 14.

    A function \(f\) from \(\mathbb{N}\) to \(\mathbb{N}\) is Turing-computable if there is a Turing machine such that for every \(n\) in the domain of \(f\text{,}\) the Turing machine, when given input \(n\text{,}\) EVENTUALLY HALTS and produces output \(f(n)\).
    🔗
    🔗
    A Turing machine can handle any number of inputs, if we adopt a convention on how the inputs are to be rendered on the tape. For instance, we can enter the ordered triple \(3\text{,}\) \(0\text{,}\) \(4\) as follows:
    🔗
    Then we can consider functions from \(\mathbb{N}^m\) to \(\mathbb{N}\text{,}\) for any positive \(m\text{.}\)
    🔗

    Subsection Connections between SETS and FUNCTIONS

    Definition 16.

    The characteristic function of a set \(A\) is the total function defined as follows: For any natural number \(n\text{,}\) \(\chi_A(n)\) is
    \begin{align*} 1, \amp \hbox{ if } n \in A, \hbox{ and } \\ 0, \amp \hbox{ if } n \not\in A. \end{align*}
    🔗
    🔗
    THINKING BACK TO COMPUTABLE SETS. It is not hard to see that a SET \(A\) of natural numbers is computable IF AND ONLY IF its characteristic function, \(\chi_A\text{,}\) is a computable function.
    🔗
    THINKING BACK TO COMPUTABLY ENUMERABLE SETS. More properly, a subset \(A\) of \(\mathbb{N}\) is computably enumerable if it is the domain of some Turing-computable function. (That’s the actual DEFINITION.)
    🔗
    (NOTE: We imagine the algorithms to be given in some order---lexicographic, usually---and we denote the Turing-computable function that is computed by the \(e\)th algorithm as “\(\varphi_e\text{,}\)” with the corresponding computably enumerable set denoted “\(W_e\text{.}\)”)
    🔗
    In case you’re wondering, here’s the connection between that official definition and the “listability” idea:
    • Suppose that \(f\) is a Turing-computable function. (We will show that there is an algorithm that lists the domain of \(f\text{.}\)) Dovetail the Turing computations for input \(1\text{,}\) input \(2\text{,}\) input \(3\text{,}\) and so on. Every time a computation converges on some input \(n\text{,}\) put \(n\) on the list. Certainly the list then consists of all numbers in the domain of \(f\text{.}\)
      🔗
    We can even prove that "if there is an algorithm that lists the elements of the set, then the set is the domain of some Turing-computable function"---but that other direction takes more work! It depends on the ideas mentioned below.
    🔗
    Historically, many different minds were working (in the 1920s and ’30s) on the question of what it meant for a function of natural numbers to be “effectively calculable.”
    • Alonzo Church proposed “\(\lambda\)-definability,”
      🔗
    • Haskell Curry proposed “definability by combinators,”
      🔗
    • Kurt Gödel and Stephen Kleene proposed “general recursiveness,” and
      🔗
    • Alan Turing proposed “computability by [Turing] machine.”
      🔗
    • We could also consider (though this idea came up later) “flowchart computability.”
      🔗
    It can be shown that all of these characterizations are EQUIVALENT: Any function that is in one category (e.g. any \(\lambda\)-definable function) must also be in all of the other categories (that is, it must be definable by combinators and Turing-computable, for instance).
    🔗
    We adopt the idea that
    Every function for which there is an intuitively effective process for computing its values can be shown to be in any of these categories and hence in all of them; for example, it must be Turing-computable and also general recursive.
    🔗
    🔗
    This is called “Turing’s Thesis”, “the Church-Turing Thesis,” or “Church’s Thesis.”
    🔗
