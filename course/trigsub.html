    Section Calculus II handout: Trigonometric substitution

    Example 4.

    (This was really Example 1 from the class notes. The markup language I’m using, "PreTeXt," imposes rules about how things are supposed to be numbered.) Evaluate \(\int \frac{1}{\sqrt{x^2-25}}\,dx\text{.}\)
    Solution.
    (The following was written in red on the class notes, which is the color that signifies we are working with respect to \(\theta\text{.}\))
    \begin{align*} {\color{red}{\hbox{Let } x }} \amp {\color{red}{ = 5\sec\theta,}}\\ {\color{red}{\hbox{ so that } dx }} \amp {\color{red}{ = 5 \sec\theta \tan\theta\ d\theta.}} \end{align*}
    🔗
    (And this was blue in the class notes--a side note that was added after we antidifferentiated the \(\theta\)-term and immediately before we drew the right-triangle diagram.) NOTE that the "Let" statement is actually saying "Let \(\theta\) be \(\sec^{-1}\left(\frac{x}{5}\right)\text{.}\)" And recall that this means that
    • \(\displaystyle \frac{x}{5} = \sec\theta\)
      🔗
    • AND (either \(0 \leq \theta \lt \frac{\pi}{2}\) or \(\pi \leq \theta \lt \frac{3\pi}{2}\)).
      🔗
    🔗
    (Back to red ink now, where the markup language will allow it.) The integral becomes
    \begin{align*} {\color{red}{\int \frac{1}{\sqrt{(5\sec\theta)^2 - 25}} \cdot 5 \sec\theta \tan\theta\ d\theta }} \amp {\color{red}{ = \int \frac{1}{\sqrt{5^2 \cdot (\sec^2\theta - 1)}} \cdot 5 \sec\theta \tan\theta\ d\theta}} \\ \amp {\color{red}{ = \int \frac{1}{\sqrt{5^2} \cdot \sqrt{(\tan\theta)^2}} \cdot 5 \sec\theta \tan\theta\ d\theta }} \\ \amp {\color{red}{ = \int \sec\theta\ d\theta }} \\ \amp {\color{red}{ = \ln\left|\sec\theta + \tan\theta\right| + C. }} \end{align*}
    🔗
    Note that because of the restrictions on \(\theta\text{,}\) \(\tan\theta\) must be nonnegative, so that \(\sqrt{(\tan\theta)^2} = \tan\theta\text{.}\) That was used in the above calculations to replace "\(\sqrt{(\tan\theta)^2}\)" with "\(\tan\theta\text{.}\)"
    🔗
    To figure out how to put the antiderivative back into \(x\)-language, we use a right-triangle diagram:
    🔗
    Now we can finish up by putting the antiderivative formula back into \(x\)-language. We rejoin the calculations above, already in progress:
    🔗
    (We start out in red ink for the "\(\theta\)-language" and will switch for the final step when we translate back to "\(x\)-language.") The integral is
    \begin{align*} {\color{red}{\cdots\ }} \amp {\color{red}{ = \ln\left|\sec\theta + \tan\theta\right| + C }} \\ \amp = \ln\left|\frac{x}{5} + \frac{\sqrt{x^2-25}}{5}\right| + C. \end{align*}
    🔗
    A subtle point: If you saw this problem in a textbook and looked up the answer in the back of the book, you might see the answer listed as “\(\int \frac{1}{\sqrt{x^2-25}}\,dx = \ln\left|x + \sqrt{x^2-25}\right| + C\text{.}\)” And that’s not what we obtained! Were we wrong? Would that book be wrong? Neither. Using our algebra and logarithm-law skills, we note that our answer can be rewritten: We have
    \begin{align*} \ln\left|\frac{x}{5} + \frac{\sqrt{x^2-25}}{5}\right| + C \amp = \ln\left|\frac{x + \sqrt{x^2-25}}{5}\right| + C\\ \amp = \ln\left(\frac{\left|x + \sqrt{x^2-25}\right|}{\left|5\right|}\right) + C\\ \amp = \ln\left(\left|x + \sqrt{x^2-25}\right|\right) - \ln\left(\left|5\right|\right) + C\\ \amp = \ln\left(\left|x + \sqrt{x^2-25}\right|\right) + C^*, \end{align*}
    where \(C^*\) is a new name for “\(-\ln 5 + C\text{.}\)” Do you see what we did there? That was the “arbitrary constant mashup”!
    🔗

    Example 6.

    (This was really Example 2 from the class notes.) Evaluate \(\int \frac{\sqrt{9-x^2}}{x^2}\,dx\text{.}\)
    Solution.
    (The following was written in red on the class notes, which is the color that signifies we are working with respect to \(\theta\text{.}\))
    \begin{align*} {\color{red}{\hbox{Let } x\ }} \amp {\color{red}{ = 3\sin\theta,}} \\ {\color{red}{\hbox{ so that } dx\ }} \amp {\color{red}{ = 3 \cos\theta\ d\theta.}} \end{align*}
    🔗
    (And this was blue in the class notes--a side note that was added after we antidifferentiated the \(\theta\)-term and immediately before we drew the right-triangle diagram.) NOTE that the "Let" statement is actually saying "Let \(\theta\) be \(\sin^{-1}\left(\frac{x}{3}\right)\text{.}\)" And recall that this means that
    • \(\displaystyle \frac{x}{3} = \sin\theta\)
      🔗
    • AND \(-\frac{\pi}{2} \leq \theta \leq \frac{\pi}{2}\text{.}\)
      🔗
    🔗
    (Back to red ink now, wherever the markup language will allow it.) The integral becomes
    \begin{align*} {\color{red}{\int \frac{\sqrt{9-9\sin^2\theta}}{9\sin^2\theta} \cdot 3 \cos\theta\ d\theta }} \amp {\color{red}{ = \int \frac{\sqrt{9 \cdot (1 - \sin^2\theta)}}{9\sin^2\theta} \cdot 3 \cos\theta\ d\theta }} \\ \amp {\color{red}{ = \int \frac{\sqrt{9} \cdot \sqrt{\cos^2\theta}}{9\sin^2\theta} \cdot 3 \cos\theta\ d\theta }} \\ \amp {\color{red}{ = \int \frac{\cos^2\theta}{\sin^2\theta}\ d\theta }} \\ \amp {\color{red}{ = \int \left(\frac{\cos\theta}{\sin\theta}\right)^2\ d\theta }} \\ \amp {\color{red}{ = \int \cot^2\theta\ d\theta }} \\ \amp {\color{red}{ = \int (\csc^2\theta - 1)\ d\theta }} \\ \amp {\color{red}{ = -\cot\theta - \theta + C. }} \end{align*}
    🔗
    (Blue ink again--a side note.) Note that because of the restrictions on \(\theta\text{,}\) \(\cos\theta\) must be nonnegative, so that \(\sqrt{(\cos\theta)^2} = \cos\theta\text{.}\) That was used in the above calculations to replace "\(\sqrt{(\cos\theta)^2}\)" with "\(\cos\theta\text{.}\)"
    🔗
    To figure out how to put the antiderivative back into \(x\)-language, we use a right-triangle diagram:
    🔗
    Now we can finish up by putting the antiderivative formula back into \(x\)-language. We rejoin the calculations above, already in progress:
    🔗
    (We start out in red ink for the "\(\theta\)-language" and will switch for the final step when we translate back to "\(x\)-language.") The integral is
    \begin{align*} {\color{red}{\cdots\ }} \amp {\color{red}{ = -\cot\theta - \theta + C }} \\ \amp = -\frac{\sqrt{9-x^2}}{x} - \sin^{-1}\left(\frac{x}{3}\right) + C. \end{align*}

    Example 8.

    (This was Example 3 from the class notes.) Evaluate \(\int \frac{1}{(x^2-6x+11)^2}\,dx\text{.}\)
    Solution.
    Note first that \(x^2-6x+11=(x-3)^2+2\text{.}\) Then the integral can be written as
    \begin{equation*} \int\ \frac{1}{((x-3)^2+2)^2}\ dx. \end{equation*}
    🔗
    (The following was written in red on the class notes, which is the color that signifies we are working with respect to \(\theta\text{.}\))
    \begin{align*} {\color{red}{\hbox{Let } x-3 }} \amp {\color{red}{ = \sqrt{2}\tan\theta,}}\\ {\color{red}{\hbox{ so that } dx }} \amp {\color{red}{ = \sqrt{2} \sec^2\theta\ d\theta.}} \end{align*}
    🔗
    (And this was blue in the class notes--a side note that was added after we antidifferentiated the \(\theta\)-term and immediately before we drew the right-triangle diagram.) NOTE that the "Let" statement is actually saying "Let \(\theta\) be \(\tan^{-1}\left(\frac{x-3}{\sqrt{2}}\right)\text{.}\)" And recall that this means that
    • \(\displaystyle \frac{x-3}{\sqrt{2}} = \tan\theta\)
      🔗
    • AND \(-\frac{\pi}{2} \lt \theta \lt \frac{\pi}{2}\text{.}\)
      🔗
    🔗
    (Back to red ink now, where the markup language will allow it.) The integral becomes
    \begin{align*} {\color{red}{\int \frac{1}{((\sqrt{2} \cdot \tan\theta)^2+2)^2} \cdot \sqrt{2} \sec^2\theta\ d\theta }} \amp {\color{red}{ = \int \frac{1}{(2 \cdot \tan^2\theta+2)^2} \cdot \sqrt{2} \sec^2\theta\ d\theta }} \\ \amp {\color{red}{ = \int \frac{1}{(2 \cdot (\tan^2\theta+1))^2} \cdot \sqrt{2} \sec^2\theta\ d\theta }} \\ \amp {\color{red}{ = \int \frac{1}{4 \cdot \sec^4\theta} \cdot \sqrt{2} \sec^2\theta\ d\theta }} \\ \amp {\color{red}{ = \int \frac{1}{2\sqrt{2}} \cdot \frac{1}{\sec^2\theta} \ d\theta }} \\ \amp {\color{red}{ = \frac{1}{2\sqrt{2}} \cdot \int \cos^2\theta \ d\theta }} \\ \amp {\color{red}{ = \frac{1}{2\sqrt{2}} \cdot \left(\frac{1}{2}\theta + \frac{1}{4}\sin(2\theta) + C_0\right) }} \\ \amp {\color{red}{ = \frac{1}{2\sqrt{2}} \cdot \left(\frac{1}{2}\theta + \frac{1}{4} \cdot 2\sin\theta\cos\theta + C_0\right) }} \\ \amp = \frac{1}{4\sqrt{2}}\tan^{-1}\left(\frac{x-3}{\sqrt{2}}\right) + \frac{1}{4\sqrt{2}} \cdot \frac{x-3}{\sqrt{(x-3)^2+2}} \cdot \frac{\sqrt{2}}{\sqrt{(x-3)^2+2}} + C \\ \amp = \frac{1}{4\sqrt{2}}\tan^{-1}\left(\frac{x-3}{\sqrt{2}}\right) + \frac{x-3}{4 \cdot (x^2-6x+11)} + C. \end{align*}
    🔗

    Example 10.

    (These were Examples 4 to 7 from the class notes.) Find the “milk equation” for each integral. You may need to “almost complete the square” to get a quadratic expression into one of the three appropriate forms.
    • (a) \(\int \frac{1}{\sqrt{1+4x^2}}\,dx\text{:}\) Let \(2x = \tan\theta\text{.}\) (“Then \(2\,dx = \sec^2\theta\,d\theta.\,\ldots\,\)”)
      🔗
    • (b) \(\int \frac{1}{x^2\sqrt{16-x^2}}\,dx\text{:}\) Let \(x = 4\sin\theta\text{.}\) (“Then \(dx = 4\cos\theta\,d\theta.\,\ldots\,\)”)
      🔗
    • (c) \(\int \sqrt{x^2-9}\,dx\text{:}\) Let \(x = 3\sec\theta\text{.}\) (“Then \(dx = 3\sec\theta \tan\theta\,d\theta.\,\ldots\,\)”)
      🔗
    • (d) \(\int \frac{1}{\sqrt{9x^2+6x+2}}\,dx\text{:}\) Note first that \(9x^2+6x+2 = (3x + 1)^2 + 1\text{.}\) Let \(3x + 1 = 1 \cdot \tan\theta\text{.}\) (“Then \(3\,dx = \sec^2\theta\,d\theta.\,\ldots\,\)”)
      🔗
